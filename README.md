## Español

Aplicación de escritorio para el registro de contactos de radioaficionados (QSOs).

### Descargar

| Plataforma | Formato | Descarga |
|------------|---------|----------|
| 🐧 Linux   | AppImage | [⬇ Descargar](https://github.com/pbracc/Open73_app/releases/download/v5.4.0/open73_5.4.0_amd64.AppImage) <!-- LINUX_ASSET --> |
| 🪟 Windows | Instalador MSI | [⬇ Descargar](https://github.com/pbracc/Open73_app/releases/download/v5.4.0/open73_5.4.0_x64_en-US.msi) <!-- WIN_ASSET --> |
| 🍎 macOS Intel | DMG | [⬇ Descargar](https://github.com/pbracc/Open73_app/releases/latest) <!-- MAC_ASSET --> |

### Instalación

**Linux**
```bash
chmod +x open73_*.AppImage
./open73_*.AppImage
```

**Windows**

Ejecutar el archivo `.msi` descargado y seguir los pasos del instalador.

**macOS Intel**

Abrir el `.dmg`, arrastrar `open73` a la carpeta Aplicaciones y ejecutar.
En el primer inicio macOS puede mostrar una advertencia de seguridad (la app no tiene
certificado Apple); hacer clic derecho → "Abrir" para confirmar.

### Download

| Platform | Format | Download |
|----------|--------|----------|
| 🐧 Linux   | AppImage | [⬇ Download](https://github.com/pbracc/Open73_app/releases/download/v5.4.0/open73_5.4.0_amd64.AppImage) <!-- LINUX_ASSET --> |

### Installation

**Linux**
```bash
chmod +x open73_*.AppImage
./open73_*.AppImage
```

**Windows**

Run the downloaded `.msi` file and follow the installer steps.

**macOS Intel**

Open the `.dmg`, drag `open73` to the Applications folder and launch it.

right-click → "Open" to confirm.
